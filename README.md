# Treasure Hunt Mission Control

Interactive embeds for the HW3 HackMD page.

- `?view=3d` — 3D map with a drone that runs real tabular Q-learning live in the browser
- `?view=terminal` — fake-hacker terminal (`help` → `scan` → `train` → `launch` → `unlock <key>`)
- no parameter — both, stacked

Edit `SECRET_MESSAGE`, `SECRET_SIGNATURE` and `AUDIO_URL` at the top of the first `<script>` in `index.html`.
